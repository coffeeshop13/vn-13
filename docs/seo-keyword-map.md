# Семантическая карта VN13

Цель: наращивать органическую видимость для русскоязычных запросов о дизайнерской и премиальной женской одежде, европейских брендах и B2B-направлениях VN13. Карта не содержит выдуманных частотностей: перед планированием публикаций их нужно проверить в Яндекс Вордстате и в фактических данных Яндекс Вебмастера / Google Search Console.

## Правило распределения интентов

- Одна страница — один основной интент и близкие формулировки.
- Коммерческие запросы без корзины, цены и карточек товара не должны обещать интернет-магазин. Для VN13 корректная цель — запрос наличия, размера, условий закупки или консультации.
- Новые страницы создаются только тогда, когда у них есть уникальный ассортимент, кейс, экспертный материал или визуалы. Не создавать десятки похожих страниц ради вариантов ключевой фразы.

## Что пока не продвигаем как основной запрос

- `купить женскую одежду`, `женская одежда недорого`, `интернет-магазин женской одежды`;
- запросы с городом, если на сайте нет подтверждённой точки продаж, адреса и локального ассортимента;
- запросы про конкретную цену, доставку, возврат или размерную сетку, пока для них нет достоверных условий на сайте.

Для этих направлений сначала нужны реальные карточки товаров или каталожные посадочные: наличие, цены или диапазоны, размерная сетка, доставка, возврат, фото конкретной модели и понятный способ оформить заказ. Иначе поисковый интент будет расходиться с посадочной страницей.

## Следующий цикл после публикации

1. Добавить и подтвердить `https://vn-13.com/sitemap.xml` в Яндекс Вебмастере и Google Search Console.
2. Через 2–4 недели выгрузить показы, клики и запросы по каждой целевой странице.
3. Усиливать только те кластеры, где есть показы и релевантный спрос: новыми уникальными материалами, лукбуками, карточками доступных моделей и ссылками с профильных изданий/партнёров.
4. Проверять каннибализацию: один запрос должен вести прежде всего на одну целевую страницу, а не на несколько почти одинаковых лендингов.

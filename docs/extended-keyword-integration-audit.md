## Applied integration

- Grouped CSV keywords by `Целевая страница`.
- Verified every CSV target has a corresponding rendered route.
- Updated per-page `keywords` arrays in `lib/extended-seo-pages.ts` from CSV clusters, capped to the 5 most important phrases used by metadata.
- Verified existing titles are under 70 characters and descriptions are around 150-160 characters.
- Existing pages already include one visible `h1`, 300+ words of body content, FAQ blocks, related links, and schema output through the shared template.
- Extended JSON-LD in `components/ExtendedSeoPage.tsx` now exposes page keyword context and category ItemList data for category-style pages.

## Notes

- No extra standalone page files were required for the 13 non-home SEO targets because the project already uses a static dynamic route with `generateStaticParams`.
- `robots.txt` is generated by `app/robots.ts`; sitemap is generated by `app/sitemap.ts`; neither blocks these pages.
- Position monitoring is intentionally not implemented in this commit because reliable rank tracking requires a search API/provider key and a schedule destination.

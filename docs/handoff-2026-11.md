## 3. Решения, которые нельзя случайно отменить
- **Позиционирование главной** определяет `docs/seo-keyword-map.md`: P1 — «дизайнерская/премиальная женская одежда», бутики, опт, дистрибуция. Главная говорит с тремя аудиториями: клиенты (каталог VN-13), бутики, бренды. Не переделывать главную под «только B2B-дистрибуцию»: это уведёт её с P1-запросов.
- **Фото марок** хранятся у нас (`public/brands/…`). У владельца есть юридическое разрешение использовать фото брендов.
- **Шрифты** подключены локально (`@fontsource`), не через Google Fonts: Google Fonts из России иногда медленный.
- **Стиль текста:** спокойный, фактический, без лозунгов и «дворовых» противопоставлений. Владелец это явно просил.

## 5. Открытые задачи (по приоритету)

2. **«Где купить».** Если kinestet.ru, sollery.fashion, «Чёрная икра» и elisastudio — партнёры VN13, сделать страницу со списком магазинов по городам и ссылками на неё со страниц марок. Ждёт ответа владельца.
3. **Страницы марок** — блоки «где купить» и FAQ сделаны. Владелец подтвердил договоры со всеми марками: «официальный дистрибьютор <марка> в России» есть на страницах марок (FAQ, первый экран, «Где купить»). Не сделано: title страниц марок (Hannoh Wessel «официальный сайт»).
4. **Данные.** Получить у владельца выгрузку запросов из Яндекс Вебмастера и частоты из Вордстата; переписать карту ключевых слов по реальному спросу.
5. **Переводы.** `lib/translations/*.json` переводят только интерфейс, а не контент страниц. Решить: полноценный английский с адресами `/en/...` и hreflang или убрать языки из переключателя.
6. **Проверка на iPhone.** Мобильное меню проверено в эмуляции; подтвердить на реальном Safari.
7. **Журнал:** у статей «Оптовая женская одежда для бутиков…» и «Как выбрать европейские бренды…» одинаковые обложки — заменить.

## 6. Как проверять перед слиянием
- `npx tsc --noEmit -p . && npm run lint && npm run build`.
- По `out/`: у каждой страницы из `out/sitemap.xml` один `<h1>`, валидный JSON-LD, внутренние ссылки со слешем и существующими страницами. Это правила `scripts/verify-live-seo.mjs`.
- Мобильные проверки в Playwright (Chromium в облачной среде: `/opt/pw-browsers`): ширина 390 и 844, нет горизонтальной прокрутки, меню открывается и закрывается, после закрытия возвращается позиция прокрутки.
